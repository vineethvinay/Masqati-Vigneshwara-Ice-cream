VIGNESHWARA MASQUAITI ICECREAMS & DAIRY
===========================================

Files:
- index.html
- style.css
- script.js
- assets/masqati-logo.png

How to run:
1. Keep the files in the same folder.
2. Double-click index.html to open it in Chrome.
3. Edit product names, MRP, reviews, phone number and address in index.html/script.js.

Technology:
HTML + CSS + JavaScript only.

The design uses CSS 3D-style effects, gradients, shadows and animations. No framework is required.
